# Dashboard workspace

Put the provided campaign dataset here as one of:

```text
dashboard/grammarly_campaign_data.xlsx
dashboard/grammarly_campaign_data.csv
```

Then run:

```bash
python dashboard/data_cleaning.py
```

Outputs will be created in:

```text
dashboard/output/
```

Use those CSVs in Looker Studio, Power BI, Google Sheets, or another visualization tool.
