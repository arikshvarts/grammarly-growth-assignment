LP Funnel Comparison
Key finding: Both LPs received near-identical traffic (1,596 vs 1,604 clicks). The performance gap is entirely in activation quality: Academic Writing LP converts 22.6% of clicks to try_grammarly vs 18.5% for Business Emails — a 4.1pp gap consistent across all 28 cohort days.
Shared leak: 43–51% of users who install Grammarly never trigger try_grammarly within 7 days. This is the highest-leverage fix and is independent of LP quality.

Data Limitations
What this dataset cannot measure: The following metrics require fields not present in this dataset and are not claimed anywhere in this report: CAC (no ad spend) · ROAS (no spend or revenue) · LTV (no subscription events) · Ad CTR (no impressions) · LP page-render CVR (no render events — did_click_lp is install-button click, not page view) · Retention beyond 7 days (outside attribution window).

QA note: All 8 automated checks returned zero flagged rows. This reflects the mock nature of the dataset and should be validated against production data before drawing conclusions about data quality.

Next instrumentation priorities: (1) Add page render events to calculate LP CVR. (2) Add ad spend per LP for CAC/ROAS. (3) Add subscription events for LTV. (4) Add onboarding step events between install and first try to diagnose the 43–51% dead install rate.
